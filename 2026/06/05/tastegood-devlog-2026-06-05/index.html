遇到的问题

Codex 的 Windows 编码问题

Codex 使用 PowerShell Set-Content 写入文件时：
- 添加 UTF-8 BOM，导致 JSON/WXML/WXSS 编译报错
- 中文全部乱码（如"早餐"→"鏃╅"）
- </text> 标签损坏为 ?/text>
- 部分 JSON 字段被删除

解决方案: 关键文件手动写，Codex 只用于纯 CSS（无中文风险）

词云动效

尝试了三种方案均未生效：
1. CSS @keyframes + animation — 小程序不支持，报 exparserScriptError
2. this.animate() API — 无效果
3. JS 物理引擎（setInterval + setData）— 帧率不稳且无效果

最终恢复静态展示。
